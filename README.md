# Melrose Cub Scout Pack 615

The pack's website. Live at **https://melrosepack615.com**.

**Not launched yet.** Search indexing is deliberately switched off, in two
places that must both be reversed at launch: the `noindex` meta tag in
`index.html`, and `robots.txt`, which currently disallows everything.

Meeting times, fees, and the contact address are confirmed and published.
The remaining gap is the pack calendar: the Parent Guide says the final
2026-2027 dates arrive in early September.

## What is in here

This repository holds only what GitHub Pages serves: `index.html`, the
`assets/` folder, `CNAME`, and `robots.txt`. Nothing is built or compiled, so
what you see here is exactly what a visitor gets.

The project's source of truth, including the copy under review, the decision
record, the research behind it, and the launch checklist, lives in a separate
private repository. Edit there, not here.
